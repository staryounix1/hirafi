# حِرْفي — منصة الحرّافين وأصحاب الخدمات الصغيرة

> تطبيق ويب عربي (RTL) يربط **الزبائن** بـ**الحرّافين** وأصحاب الخدمات الصغيرة، على نفس منطق **inDrive**: الزبون ينشر طلبه ويقترح ميزانية، والحرّافون يتنافسون بعروضهم، والزبون يقارن ويتفاوض ويختار.

بدل «سائق ↔ راكب» في inDrive، هنا **«حرّاف ↔ زبون»**: سباكة، كهرباء، نجارة، صباغة، تكييف، تنظيف، نقل أثاث، إصلاح إلكترونيات، خياطة، تصوير، دروس خصوصية، قضاء الأغراض، الوقوف فالطابور، والكراء.

---

## ✨ الفكرة في سطرين

الزبون ينشر مشكلته (الفئة، الوصف، الميزانية المقترحة، الموقع، الوقت) → الحرّافون القريبون يقدّمون عروضهم (سعر + مدة + رسالة) → الزبون يقارن، **يتفاوض على السعر**، ويختار → بعد التنفيذ تقييم متبادل ومراجعات.

## 🚀 التشغيل محلياً

### المتطلبات
- Node.js **≥ 20.19**
- pnpm **11+**
- قاعدة بيانات **PostgreSQL**

### الخطوات

```bash
# 1) تثبيت الحزم
pnpm install

# 2) إعداد متغيّرات البيئة
cp .env.example .env
# ثم عدّل DATABASE_URL و JWT_SECRET داخل .env

# 3) إنشاء جداول قاعدة البيانات
pnpm db:migrate

# 4) تشغيل خادم التطوير (الواجهة + الـAPI معاً)
pnpm dev
```

يفتح التطبيق على `http://localhost:3000`.

### البناء للإنتاج

```bash
pnpm build     # يبني الواجهة (vite) والخادم (esbuild)
pnpm start     # يشغّل dist/index.js
```

### فحوص الجودة

```bash
pnpm typecheck   # فحص أنواع TypeScript
pnpm test        # تشغيل الاختبارات
```

## ✅ الميزات المنفّذة

### للزبون
- نشر طلب جديد (فئة الخدمة، الوصف، الميزانية المقترحة، الموقع، الصور)
- قائمة طلباته مع تتبّع الحالة: **منشور → عروض → مقبول → قيد التنفيذ → منتهي**
- شاشة العروض الواردة مع **قبول / تفاوض / رفض**
- التفاوض على السعر: عرض مضاد بأزرار سريعة (منتصف الطريق، خصم 10%، خصم 20%)
- اختيار الحرّاف ومتابعة التنفيذ
- تقييم الحرّاف بالنجوم بعد الإنجاز

### للحرّاف
- تصفّح الطلبات القريبة مع فلترة حسب الفئة والمسافة والميزانية
- إرسال عرض سعر (سعر + مدة + رسالة)
- إدارة العروض المرسلة والمقبولة
- الملف الشخصي: المهارات، سنوات الخبرة، صور أعمال سابقة، التقييم
- شارة **«موثّق»**

### مشترك
- محادثة داخلية بين الطرفين لكل طلب
- محفظة وسجل مدفوعات بسيط (مع عمولة المنصة)
- إشعارات داخل التطبيق
- تقييم متبادل ومراجعات وسجل الأعمال
- تصميم عربي RTL متجاوب مع الهاتف

## 🚫 خارج النطاق

هذه النسخة **لا** تتضمّن — بشكل مقصود:

- ❌ **GPS / خرائط حقيقية** — الموقع يُختار كـ«مدينة + حي» من قائمة، والمسافة تُعرض «قريب / متوسط / بعيد»
- ❌ **بوابة دفع حقيقية** — المحفظة سجلّ داخلي فقط
- ❌ **SMS / بريد إلكتروني** — لا رسائل تُرسل خارج التطبيق
- ❌ **إشعارات دفع (Push)** — الإشعارات داخل التطبيق فقط
- ❌ **لوحة إدارة** — لا واجهة إشراف للمشرفين
- ❌ **رفع مستندات للتوثيق** — شارة «موثّق» تُقلب من الملف مباشرة
